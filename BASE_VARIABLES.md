# Base CSS Custom Properties

This document describes all `--base-*` CSS custom properties generated by `generateBaseTheme()` in `src/generators/base.ts`.

## Overview

The base layer provides a shared foundation for theming multiple KeenMate web components. Instead of each component defining its own colors, they reference base variables via CSS fallback chains:

```css
/* Component CSS */
--ms-accent-color: var(--base-accent-color, #3b82f6);
```

This enables:
- **Cascading themes**: Set `--base-*` once, all components inherit
- **Component overrides**: Set `--ms-*` or `--drp-*` to override specific components
- **Standalone mode**: Components work without base vars (use SCSS defaults)

### Text Color Levels (FluentUI-style)

Text colors use a numbered level system inspired by Microsoft FluentUI. Lower numbers = higher emphasis.

| Variable | Purpose | Derivation | Example Value |
|----------|---------|------------|---------------|
| `--base-text-color-1` | Headers, titles, high-emphasis | Input `text` color (full contrast) | `#f9fafb` |
| `--base-text-color-2` | Body text, labels | `mix(text, background, 85%)` | `#e5e7eb` |
| `--base-text-color-3` | Secondary content, subtitles | `mix(text, background, 60%)` | `#9ca3af` |
| `--base-text-color-4` | Hints, placeholders, captions | `mix(text, background, 40%)` | `#6b7280` |
| `--base-text-on-accent` | Text on accent backgrounds | `contrast(accent)` auto-calculated | `#ffffff` |

**Note:** `--base-text-on-accent` is a special variable that auto-calculates contrast against the accent color, not the background.

## Usage in Components

### Setting Up Fallback Chains

Components should define CSS variables with base fallbacks in their `:host` block:

```scss
// In component's _css-variables.scss
:host {
  // Text color levels with base fallbacks
  --ms-text-color-1: var(--base-text-color-1, #{$ms-text-color-1});
  --ms-text-color-2: var(--base-text-color-2, #{$ms-text-color-2});
  --ms-text-color-3: var(--base-text-color-3, #{$ms-text-color-3});
  --ms-text-color-4: var(--base-text-color-4, #{$ms-text-color-4});

  // Color with base fallback
  --ms-accent-color: var(--base-accent-color, #{$ms-accent-color});

  // Semantic variable referencing text level
  --ms-input-color: var(--base-input-color, var(--ms-text-color-1));

  // Full border property (allows width/style/color control)
  --ms-input-border: var(--base-input-border, 1px solid var(--ms-border-color));
}
```

### Using Variables in Styles

```scss
// In component's _input-dropdown.scss
.ms__input {
  background: var(--ms-input-background);
  color: var(--ms-input-color);
  border: var(--ms-input-border);

  &:hover:not(:focus):not(:disabled) {
    border: var(--ms-input-border-hover);
  }

  &:focus {
    border: var(--ms-input-border-focus);
  }
}
```

## Theme Generator Integration

The `generateBaseTheme()` function produces all `--base-*` variables:

```typescript
import { generateBaseTheme } from '@keenmate/theme-designer';

const baseTheme = generateBaseTheme({
  background: '#1f2937',
  text: '#f9fafb',
  accent: '#3b82f6'
});

// Result: { '--base-accent-color': '#3b82f6', ... }
```

Component generators (like `generateMultiselectTheme()`) should **NOT** set variables that have base equivalents. They only set component-specific variables for states without base fallbacks (e.g., option hover states, checkbox colors, badge styles).

## Dark/Light Mode Detection

The generator automatically detects dark vs light mode using `getLightness(background) < 50`:

- **Dark mode**: Hover states lighten, shadows are stronger
- **Light mode**: Hover states darken, shadows are softer

Text contrast on accent backgrounds is automatically calculated using WCAG luminance formulas.
